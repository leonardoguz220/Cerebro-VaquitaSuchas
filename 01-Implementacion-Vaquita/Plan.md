# Plan

El **cómo**: por cada spec hay un plan, un modelo de datos y un contrato de API. Se congelan al aprobar el plan; cambiarlos requiere un PR que avise a las otras dos capas ([[Desarrollo-por-tarea]]).

Orden de dependencia: base de datos publica el modelo ([[BD]]), backend publica el contrato ([[Backend]]) y frontend arranca con datos simulados sobre ese contrato ([[Frontend]]).
